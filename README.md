# คู่มือระบบบันทึกการสอบเทียบ บำรุงรักษา และทวนสอบเครื่องมือ Testo
**ห้องปฏิบัติการตรวจวิเคราะห์ / ฝ่ายตรวจวิเคราะห์ — บริษัท อีสเทิร์น ไทย คอนซัลติ้ง 1992 จำกัด**

ระบบประกอบด้วย 2 ส่วนที่ทำงานเชื่อมโยงกันอัตโนมัติ:
1. **Frontend ([`index.html`](./index.html))**: หน้าเว็บแอปสำหรับบันทึกข้อมูล 3 แบบฟอร์ม และ **แท็บที่ 4 สำหรับค้นหาและดาวน์โหลดข้อมูลย้อนหลัง** (ส่งออกเป็น PDF, Excel `.xls`, CSV `.csv` และ Word `.doc`)
2. **Backend ([`Code.gs`](./Code.gs))**: Google Apps Script สำหรับจัดเก็บข้อมูลลงฐานข้อมูลใน Google Sheet, ดึงข้อมูลย้อนหลัง และสร้างหน้าแบบฟอร์มมาตรฐานทั้ง 3 ไฟล์โดยอัตโนมัติ

## 🔄 การทำงานและการเชื่อมโยงข้อมูลอัตโนมัติ (4 แท็บเมนู)

1. **แท็บที่ 1: บันทึกการสอบเทียบและบำรุงรักษาเครื่องมือ (แบบฟอร์มที่ 1)**
   - บันทึกข้อมูลลงฐานข้อมูล `DB_Maintenance_Cal` และจัดเรียงลงหน้าแบบฟอร์ม **`Form1_สอบเทียบและบำรุงรักษา`** อัตโนมัติ
   - **เชื่อมโยงอัตโนมัติ:** หากติ๊กรายการตรวจสภาพเป็น *"ต้องแก้ไข"* หรือผลการสอบเทียบ *"ไม่ผ่าน"* ระบบจะส่งข้อมูลความผิดปกติเข้า **`Form2_ประวัติเครื่องมือ`** (แบบฟอร์มที่ 2) ให้พร้อมกันทันที

2. **แท็บที่ 2: บันทึกประวัติเครื่องมือ - ความเสียหาย/ซ่อมแซม (แบบฟอร์มที่ 2)**
   - บันทึกข้อมูลลงฐานข้อมูล `DB_Repair_History` และจัดเรียงลงหน้าแบบฟอร์ม **`Form2_ประวัติเครื่องมือ`** อัตโนมัติ

3. **แท็บที่ 3: Flue Gas Analyzer Verification - ทวนสอบค่าก๊าซ NO, NO2, SO2 (แบบฟอร์มที่ 3)**
   - คำนวณค่า `Difference (PPM) = Response - Standard` และ `Calibration Error (%) = ((Response - Standard) / Standard) × 100` อัตโนมัติแบบ Real-time
   - บันทึกข้อมูลลงฐานข้อมูล `DB_Gas_Verification` และจัดหน้าลงแบบฟอร์ม **`Form3_Gas_Verification`** อัตโนมัติ
   - **เชื่อมโยงอัตโนมัติ:** ส่งผลสรุปการทวนสอบ (ค่า Error สูงสุด, เกณฑ์ยอมรับ, ผลผ่าน/ไม่ผ่าน, วันที่) ไปบันทึกต่อท้ายใน **`Form1_สอบเทียบและบำรุงรักษา`** (แบบฟอร์มที่ 1) ให้ทันที

4. **แท็บที่ 4: 📂 ค้นหาและดาวน์โหลดข้อมูลย้อนหลัง (History & Export)**
   - เลือก **แบบฟอร์ม (1, 2 หรือ 3)** + เลือก **หมายเลขเครื่อง (S/N)** + เลือก **ช่วงวันที่ย้อนหลัง**
   - สำหรับแบบฟอร์มที่ 3 สามารถเลือกใบทวนสอบก๊าซย้อนหลังแต่ละครั้งจาก Dropdown ได้ทุกใบ
   - แสดงตัวอย่างแบบฟอร์มจริงบนหน้าเว็บ และมีปุ่มกดดาวน์โหลดได้ 4 รูปแบบ:
     - **🖨️ พิมพ์ / บันทึกเป็น PDF** (หน้าตาตรงตามแบบฟอร์มมาตรฐาน)
     - **📊 ดาวน์โหลด Excel (`.xls`)** (รักษาโครงสร้างตารางและหัวกระดาษตามแบบฟอร์ม)
     - **📑 ดาวน์โหลด CSV (`.csv`)** (สำหรับเปิดใน Excel)
     - **📝 ดาวน์โหลด Word (`.doc`)** (เปิดแก้ไขต่อใน Microsoft Word ได้ทันที)

## 📥 การดูย้อนหลังและดาวน์โหลดจากใน Google Sheets โดยตรง

ในไฟล์ Google Sheets หน้าแบบฟอร์มทั้ง 3 หน้า (`Form1_สอบเทียบและบำรุงรักษา`, `Form2_ประวัติเครื่องมือ`, `Form3_Gas_Verification`) รองรับการกรองย้อนหลังเช่นกัน:
- **ใน `Form1` และ `Form2`:** เลือก `S/N` ในช่องสีเหลือง และระบุ `กรองตั้งแต่วันที่` - `ถึงวันที่` ในช่องสีฟ้า ตารางจะกรองเฉพาะช่วงเวลาที่ต้องการให้อัตโนมัติ
- **ใน `Form3_Gas_Verification`:** เลือก `S/N` ที่เซลล์ `F3` และคลิกเลือก **ครั้งที่ทวนสอบย้อนหลัง** ที่เซลล์ `F4` เพื่อสลับดูใบ Verification ย้อนหลังใบใดก็ได้
- ที่เมนูด้านบน **"📋 ระบบแบบฟอร์ม Testo (ETC 1992)"** > คลิก **"📥 ดาวน์โหลดหน้าแบบฟอร์มปัจจุบัน (PDF / Excel)"** เพื่อดาวน์โหลดเป็นไฟล์ PDF ขนาด A4 หรือไฟล์ `.xlsx` ได้ในคลิกเดียว

## 🚀 ขั้นตอนการอัปเดตโค้ดขึ้นระบบจริง

1. เปิดไฟล์ **Google Sheets** > ไปที่เมนู **ส่วนขยาย (Extensions)** > **Apps Script**
2. คัดลอกโค้ดทั้งหมดจากไฟล์ [`Code.gs`](./Code.gs) ไปวางทับโค้ดเดิม แล้วกด **บันทึก (Save)** 💾
3. กดปุ่ม **ทำให้ใช้งานได้ (Deploy)** > เลือก **จัดการการทำให้ใช้งานได้ (Manage deployments)**
4. คลิกไอคอน **รูปดินสอ ✏️ (แก้ไข)** > ในช่อง **เวอร์ชัน (Version)** เลือกเป็น **"เวอร์ชันใหม่ (New version)"** > กด **ทำให้ใช้งานได้ (Deploy)**
5. นำไฟล์ [`index.html`](./index.html) ไปเปิดใช้งาน หรืออัปโหลดขึ้น GitHub Pages / Netlify เพื่อใช้งานได้ทันที
