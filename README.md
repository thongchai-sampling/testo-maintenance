# ระบบรายงานการตรวจสอบและบำรุงรักษาเครื่องวัดก๊าซ Testo (testo-maintenance)

เว็บแอปพลิเคชันสำหรับบันทึกผลการตรวจสอบและบำรุงรักษาเครื่องวัดประสิทธิภาพการเผาไหม้และก๊าซไอเสีย Testo (รองรับ Testo 350 XL และ Testo 350 New) พร้อมระบบแยกตรวจเช็คสถานะเซ็นเซอร์ 5 ชนิด, ระบบพิมพ์รายงาน/บันทึก PDF และรองรับการทำงานแบบ Offline พร้อมคิว Sync อัตโนมัติ

---

## 🌟 ฟีเจอร์หลัก (Features)

1. **รายการตรวจเช็ค 9 ข้อสมบูรณ์:**
   - 1. ฟิลเตอร์กรองฝุ่นก่อนเข้าเซ็นเซอร์
   - 2. การทำงานของปั๊มดูดอากาศ
   - 3. ความพร้อมของแบตเตอรี่
   - 4. ความสะอาดของเครื่องมือ
   - 5. เซ็นเซอร์ O₂ (Oxygen)
   - 6. เซ็นเซอร์ CO (Carbon Monoxide)
   - 7. เซ็นเซอร์ NO (Nitric Oxide)
   - 8. เซ็นเซอร์ NO₂ (Nitrogen Dioxide)
   - 9. เซ็นเซอร์ SO₂ (Sulfur Dioxide)
2. **พิมพ์ใบรายงาน / บันทึกเป็น PDF (Print / Export PDF):**
   - มีปุ่มพิมพ์รายงานหรือเซฟเป็นไฟล์ PDF ได้ทันที ออกแบบให้มีขนาดพอดีกับกระดาษ A4 สวยงาม พร้อมช่องลงลายมือชื่อผู้ตรวจสอบและผู้ควบคุมงาน
   - สามารถกดพิมพ์จากฟอร์มปัจจุบัน, พิมพ์หลังกดส่งสำเร็จ, หรือเลือกพิมพ์ย้อนหลังจาก "ประวัติบันทึก" ได้
3. **รองรับการทำงาน Offline (ไม่มีอินเทอร์เน็ต):**
   - เมื่อไม่มีสัญญาณเน็ต ระบบจะบันทึกข้อมูลเก็บไว้ในหน่วยความจำของอุปกรณ์ (LocalStorage) อัตโนมัติ
   - แสดงสถานะเครือข่าย (ออนไลน์/ออฟไลน์) และจำนวนรายการที่รอ Sync
   - มีปุ่ม "Sync ทันที" เมื่อกลับมาเชื่อมต่อสัญญาณเน็ต
4. **ระบบจัดการประวัติในเครื่อง (History):**
   - ดูรายการย้อนหลังที่เคยบันทึกไว้ในอุปกรณ์
   - มีสถานะระบุชัดเจนว่ารายการใดส่งขึ้น Google Sheet แล้ว (Synced) หรือรอส่ง (Pending)
   - จัดการลบ หรือเลือก Sync เฉพาะรายการได้

### 2. วิธีการติดตั้งใน Google Apps Script

1. เปิด Google Sheet ที่ต้องการเก็บข้อมูล
2. ไปที่เมนู **ส่วนขยาย (Extensions)** &rarr; **Apps Script**
3. คัดลอกโค้ดทั้งหมดจากไฟล์ [`google-apps-script.js`](./google-apps-script.js) ไปวางแทนที่ในไฟล์ `Code.gs`
4. เลือกฟังก์ชัน **`setupHeaders`** ที่แถบด้านบน แล้วกดปุ่ม **เรียกใช้ (Run)** 1 ครั้ง เพื่อให้ระบบสร้างและจัดสไตล์หัวตารางในชีตให้โดยอัตโนมัติ
5. กดปุ่ม **การทำให้ใช้งานได้ (Deploy)** ที่มุมขวาบน &rarr; **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
   - เลือกประเภท: **เว็บแอป (Web app)**
   - ดำเนินการในฐานะ (Execute as): **ฉัน (Me)**
   - ผู้มีสิทธิ์เข้าถึง (Who has access): **ทุกคน (Anyone)** *(สำคัญมาก เพื่อให้หน้าเว็บส่งข้อมูลได้โดยไม่ต้องล็อกอิน)*
6. กด **ทำให้ใช้งานได้ (Deploy)** แล้วคัดลอก **URL เว็บแอป (Web App URL)**
7. นำ URL ที่ได้ มาวางในตัวแปร `GOOGLE_SCRIPT_URL` ในไฟล์ [`index.html`](./index.html)
